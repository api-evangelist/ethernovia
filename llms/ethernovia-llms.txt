# Ethernovia

> Ethernovia is a San Jose, California semiconductor company building deterministic Ethernet networking silicon for software-defined vehicles, robotics and physical AI: single-pair (T1) Ethernet PHYs from 1G to 10G, deterministic packet processors and switches, and the High-Speed Sensor Bridge platform that bridges GMSL 2/3 cameras and CAN FD/XL onto 10GBASE-T1 Ethernet for NVIDIA Holoscan, Orin and Thor compute.

Generated by API Evangelist on 2026-08-04 from the public Ethernovia web surface. Ethernovia does not publish an llms.txt of its own (https://www.ethernovia.com/llms.txt returns 404).

Important for agents: **Ethernovia publishes no public product API.** Its tools, software binaries, source-code drivers, header files and plug-in APIs are distributed to customers under NDA through the Ethernovia Customer Portal and governed by a separate EULA. The only machine-readable contract reachable without credentials is the Customer Portal's own Strapi backend, whose Swagger UI is public while every data endpoint returns HTTP 403 anonymously.

## APIs

- [Ethernovia Customer Portal API](https://portal-admin.ethernovia.com/documentation): Strapi 5 REST API behind portal.ethernovia.com — product catalog, documents, software packages, downloads, groups, audit trails. Base URL https://portal-admin.ethernovia.com/api. Bearer JWT required; 403 anonymous.
